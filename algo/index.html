競プロ アルゴリズム図鑑

AtCoder の茶色から青色を目指すときに避けて通れないアルゴリズムを、12 個に絞ってまとめました。どのページも「考え方 → 動かして見る → 実装 (C++ / Python) → ハマりどころ → 典型問題」の順です。図は 1 ステップずつ進められるので、頭の中で追えるようになるまで何度でも動かしてください。

1. 図を動かすまず再生して全体を眺め、次に ◀ ▶| で 1 手ずつ。「次に何が起きるか」を予想してから進めると定着します。
2. 写経して提出実装は写して、典型問題を 1 問解いて通るまでが 1 セット。C++ でも Python でも同じ構造です。
3. 型を言葉で持つ「区間の和 → 累積和」「K 回先 → ダブリング」のように、問題文の形と道具を結びつけて覚えます。

この先 (青以降で必要になるもの)

この図鑑に入れていない主なもの。上の 12 個が体に入ってから触ると吸収が早いです。

  • DP の応用: bit DP (巡回セールスマン)、桁 DP、木 DP、区間 DP、expected value DP
  • グラフ: トポロジカルソート、強連結成分分解、最小全域木 (クラスカル法)、LCA (ダブリング の続き)、最大流
  • データ構造: BIT (Fenwick 木)、遅延評価セグメント木、優先度付きキューの応用、平衡二分木の代替 (set / multiset)
  • 文字列: Z アルゴリズム、ローリングハッシュ、Trie
  • 数学: 包除原理、二項係数の前計算、行列累乗、拡張ユークリッド、中国剰余定理

使っている道具

  • C++ は g++ -std=c++17 以降を想定。#include <bits/stdc++.h> と using namespace std; を省略しています。
  • Python は 3.8 以降。再帰を使う場合は sys.setrecursionlimit を上げ、速度が必要なら PyPy を使います。
  • 計算量は「1 秒に約 10^8 回」を目安に。N ≤ 20 なら 2^N、N ≤ 3000 なら N^2、N ≤ 2×10^5 なら N log N が通る感覚です。
