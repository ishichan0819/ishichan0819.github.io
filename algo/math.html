整数論の道具

数え上げや約数の問題で毎回出てくる 4 つの道具です。エラトステネスの篩 (素数表)、試し割りの素因数分解、繰り返し二乗法 (a^n mod p を O(log n))、mod 逆元 (割り算を mod の世界でやる)。「10^9+7 で割った余りを求めよ」を見たら全部使います。

考え方

篩　2 から順に、まだ消えていない数 p は素数。その倍数 2p, 3p, … を消す。p·p から始めてよい (それ未満はもっと小さい素数で消えている)。O(N log log N)。
繰り返し二乗法　a^n は n を 2 進数で見て、a, a^2, a^4, … のうちビットが立っている所だけ掛ける。O(log n)。逆元: p が素数なら フェルマーの小定理 a^(p−1) ≡ 1 より a^(−1) ≡ a^(p−2)。
  • 素因数分解は √N まで試し割り。N ≤ 10^12 でも 10^6 回。
  • 約数の列挙も √N まで。i が割り切れたら i と N/i の両方。
  • 階乗と逆元を前計算しておくと二項係数 nCk が O(1)。
  • gcd はユークリッドの互除法 (std::gcd / math.gcd)。lcm = a / gcd · b (先に割る)。

動かして見る

1 から 60 のエラトステネスの篩。黄色が今の素数 p、赤が消される倍数、緑が確定した素数です。

実装

計算量とハマりどころ

  • 篩 O(N log log N)、N = 10^7 まで実用的。素因数分解 O(√N)。modpow O(log n)。
  • 掛け算のたびに mod を取る。a * b は 10^18 まで行くので long long。3 つ以上掛けるときは 2 つずつ。
  • 引き算は (a − b + MOD) % MOD。負の余りを出さない。
  • 逆元は MOD が素数のときだけ a^(MOD−2)。合成数なら拡張ユークリッド。
  • 「余りを求めよ」で分母が出てくる (平均、確率、二項係数) → 逆元。
  • Python の pow(a, -1, m) (3.8+) でも逆元が取れる。

典型問題のパターン

  • N 以下の素数の個数、区間 [L, R] の素数 (区間篩)
  • 約数の個数・総和 (素因数分解から (e1+1)(e2+1)…)
  • 経路数や並べ方を mod 10^9+7 で数える (二項係数)
  • 「確率を mod で答えよ」→ 分子 × 分母の逆元
  • a^b の下 k 桁、a^b mod m を大きな b に対して
