AWS 基盤パズル

AWS の構成図を自分で描きながら、ネットワークからプラットフォームエンジニアリングまでを学ぶ演習です。部品をインターネット・組織・アカウント・リージョン・VPC・サブネットなどの枠に置き、流れを矢印で描きます。お題は全45問。ページを開くたびに、まだ出ていないお題からランダムに選ばれます。

1. 置く部品をタップしてから、置きたい枠をタップします (パソコンではドラッグでも置けます)。AWS の外か中か、どの組織・アカウント・リージョン・VPC・サブネットかを考えます。使わない部品も混ざっています。
2. 矢印を描く置いた部品を 2 つ続けてタップすると、1 つ目から 2 つ目へ矢印が引けます。矢印は、通信やデータ・設定が流れる向きに描きます。ネットワークのお題 (8問) では向きも採点し、ほかのお題では向きは問いません。
3. 答え合わせ置き場所と矢印を採点します。解答例では、部品ごとの置き場所の理由、矢印ごとの意味、参考にした AWS 公式資料や大手 IT の事例を確かめられます。

    • 解答例は、公式資料や事例でよく使われる「型」の1つです。要件によっては別の組み方も正解になります (「代わりに使える部品」は、正しい枠に置けば減点しません)。
    • マルチアカウントのお題では、アカウントの中のリージョンの枠を省いて描いているところがあります。IAM や Organizations のようにリージョンを選ばないものは、アカウントや組織の枠に置きます。
    • 構成図の枠の色と線 (リージョンは点線、VPC は実線、パブリックサブネットは緑など) は、AWS のアーキテクチャ図の描き方をまねています。部品の略号は説明のためのもので、AWS 公式のアイコンではありません。
    • サービス名と仕様は 2026年9月時点の公開情報にもとづいています。AWS の公式教材ではありません。サービスの終了・名称変更は解説の中で触れています。
    • 自己ベストの点数は、このブラウザの中にだけ保存されます。
