AWS 基盤パズル

AWS の構成図を、サービスの配置と通信経路から組み立てる演習です。外部、AWS Cloud、リージョン、VPC、AZ、サブネットの関係を考えながら部品を置いてください。従来のサービス接続問題も全39問残しています。

1. 配置を考える部品を選び、図の領域をクリックして置きます。ドラッグでも配置できます。AWS の外側、リージョン、VPC、AZ、サブネットを見分けましょう。
2. 経路をつなぐ「経路をつなぐ」に切り替え、始点と終点を順に選びます。矢印が通信やデータの向きを示します。
3. 答え合わせ配置と経路を別々に採点します。解答例では二つの AZ にまたがる構成と、矢印ごとの理由を確認できます。
構成図演習マルチ AZ の Web システム

二つの AZ で動く Web システムを組み立てる

利用者向けの Web サイトを東京リージョンに構築します。CloudFront は静的ファイルを S3 から配信し、動的リクエストは ALB から二つの AZ の EC2 に渡します。DB は非公開サブネットで冗長化し、社内データセンターとは VPN で接続します。

  1. 1利用者からの入口と静的・動的コンテンツの経路を表す
  2. 2VPC と二つの AZ、それぞれの公開・非公開サブネットに適切な部品を置く
  3. 3二つの EC2、RDS の主系・待機系、オンプレミス接続を矢印で表す
配置: 部品を選択 → 図の領域をクリック接続: 始点 → 終点スマートフォンでは下の「配置先」も使えます

図は横にスクロールできます。矢印は通信・データの向きです。AWS Cloud や VPC の枠そのものは接続線ではありません。参考にした AWS の構成図

1. お題を読む会社の状況と要件を読んで、どのブロックが必要か考えます。使わない「ひっかけ」のブロックも混ざっています。
2. ブロックをつなぐ役割別の領域にあるブロックを2つタップすると線が引けます。線をタップすると消えます。ドラッグで並べ替え。
3. 答え合わせ要件ごとの達成度を確認。解答例は矢印付きの構成図で、要件ごとの経路と線の意味を追えます。

    役割別の領域は配置の目安で、正解の接続を示しません。ブロックを2つ続けてタップ(またはEnter)すると線が引けます。選択を外すには空いている所をタップ(Esc)。
    • 解答例は、公式資料や事例でよく使われる「型」の1つです。要件によっては別の組み方も正解になります(代わりに使えるブロックは、つないでも減点しません)。
    • サービス名と仕様は 2026年9月時点の公開情報にもとづいています。AWS の公式教材ではありません。サービスの終了・名称変更は解説の中で触れています。
    • 自己ベストの点数は、このブラウザの中にだけ保存されます。
