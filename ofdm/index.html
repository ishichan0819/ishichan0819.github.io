狭い帯域で速く送る

照明用の白色LEDは、明るさをすばやく変えるのが苦手です。蛍光体を使う白色LEDの帯域(応答できる速さ)は数MHz程度しかありません。それでも研究では、同じようなLEDで数百Mb/sが出ています。主役は Wi-Fi や地デジでも使われる OFDM。ただし光には「実数で、マイナスがない」という制約があり、そのままでは使えません。4つの実験で、その工夫をたどります。

① OOKを速くすると、目が閉じる

LEDは急に明るさを変えられず、ゆっくり追いかけます。ビットを速くすると、前のビットの名残が次のビットに重なり(符号間干渉)、0と1を見分けられなくなります。2ビットぶんの波形を何本も重ね描きしたアイパターンの「目」の開き具合で確かめます。

② 周波数で分けて並べる: OFDM とエルミート対称

OFDMは、速い1本の流れを、ゆっくりした多数のサブキャリア(周波数の違う波)に分けて同時に送ります。各サブキャリアに QPSK などの信号点を1つずつ載せ、逆FFT(IFFT)でまとめて足し合わせたものが送信波形です。ただしIFFTの出力はふつう複素数。LEDが出せるのは実数(明るさ)だけです。そこで、k番目と N−k番目に鏡写し(複素共役)の値を置くエルミート対称を使います。

③ マイナスをなくす: DCO-OFDM と ACO-OFDM

OFDMの波形は0を中心に上下に振れます。LEDの明るさはマイナスにできないので、2つのやり方があります。DCO-OFDMは波形全体を底上げ(DCバイアス)して、それでもはみ出た下側を切ります。ACO-OFDMは奇数番目のサブキャリアだけにデータを載せ、マイナス側をすべて切り落とします。切り落としで生まれるゆがみが偶数番目にだけ落ち、データが無傷で残るという工夫です。

④ 帯域いっぱいに詰め込む: ビット割り当て

LEDは高い周波数ほど弱くなるので、低い周波数のサブキャリアはSNRが高く、高い周波数は低くなります。OFDMならサブキャリアごとに信号点の数を変えられます(ビット割り当て)。SNRが高いところには256QAM、低いところにはQPSK、ほとんど届かないところは使わない。誤り訂正で直せる限界として使われる BER 3.8×10⁻³ を目安に、LEDの帯域の何倍まで速くできるかを見ます。

見えたこと

  • LEDは遅い。OOKを速くすると、LEDの応答が追いつかず目が閉じる。3 MHzのLEDでは十数Mb/sが目安。
  • OFDMは周波数ごとに分けて並べる。光では実数が必要なので、エルミート対称で鏡写しを置く。そのぶんデータを運べるサブキャリアは半分になる。
  • マイナスには2つの解き方。DCOは底上げ(照明の明るさにもなる)で周波数を有効に使えるが、電力の多くをDCに使う。ACOは奇数だけを使ってゆがみを偶数に逃がし、電力効率がよいが運べるビットは半分以下。
  • SNRに合わせてビットを割り当てると、LEDの帯域の何十倍もの速さが出る。帯域の外でも、SNRが残っている限りビットを載せられる。
  • ここでは入れていないもの: サイクリックプレフィックス、同期、チャネル推定、LEDの上側の飽和(非線形性)、部屋の反射による遅れ(室内VLCの②)。

計算に使った式とパラメータ

LEDの応答 (①④)

H(f) = 1 / (1 + j f / f3dB),　τ = 1 / (2π f3dB)

①では 1ビットを40サンプルに分け、y[n] = a·y[n−1] + (1−a)·x[n]、a = e−2π f3dB Ts で計算しています。

OFDM とエルミート対称 (②)

x[n] = (1/√N) Σk=0N−1 X[k] ej2πkn/N,　X[N−k] = X[k]*,　X[0] = X[N/2] = 0　⇒　x[n] は実数

DCO-OFDM と ACO-OFDM (③)

DCO: xDCO[n] = max(0, x[n] + β·σx)　→　受信側では X[k] が Φ(β) 倍 + ゆがみ
ACO: X[k] = 0 (k が偶数),　xACO[n] = max(0, x[n])　→　奇数番目は X[k]/2、ゆがみは偶数番目だけ
Eb(電気) = E[xc²]·N / (1シンボルのビット数),　雑音の分散 = N0/2 (サンプルごと)

Φ はガウス分布の累積分布関数。信号点はグレイ符号の正方形QAM。BER曲線はモンテカルロ法で、誤りが150ビットたまるか40万ビット送るまで数えています。

ビット割り当て (④)

SNRk = SNR0 · |H(fk)|²,　fk = k·Δf,　Δf = B / (N/2)
BER ≈ (4/b)(1 − 2−b/2) · Q( √(3·SNR / (2b − 1)) )　(b ビット/信号点、b = 1 は Q(√(2·SNR)))
速さ R = Σ bk·Δf　(bk は BER ≤ 3.8×10⁻³ を満たす最大のビット数、最大8)

正方形でない信号点(8QAMなど)にも同じ近似式を使っています。3.8×10⁻³ は冗長7%の硬判定誤り訂正で直せる目安としてよく使われる値です。
