4色で色を送る

CSK は、LED の色を信号点にして送る変調方式です。IEEE 802.15.7 の CSK は、3色の LED で色度図の上に三角形を作り、その中に信号点を置きます(ここでは TLED と呼びます)。Singh らは、青・シアン・黄・赤の4色で四角形を作る方式を提案しました(QLED CSK)。このページでは2つを並べて、何が良くなるのかを確かめます。

① 三角形と四角形

色度図の上の信号点です。点を押すと、その色を出すために各 LED をどれだけ光らせるかが分かります。どちらの方式も、LED の光の合計はいつも同じです(1W)。そのため、色が変わっても明るさはちらつきません。

② 距離を比べる

雑音に強いかどうかは、いちばん近い信号点どうしの距離(最小距離)で決まります。色度図の上では、四角形は三角形より少し広いだけです。ところが受信側は、色ではなく、色フィルタを付けた受光素子で各 LED の強さを測ります。強さの空間(信号空間)で測ると、差ははっきり開きます。

QLED の 4-CSK は、どのシンボルも LED を1色だけ光らせます。4つのシンボルは4次元の空間で互いに直交し、距離は √2 = 1.414 です。TLED の 4-CSK は、白 (1/3, 1/3, 1/3) が残りの3点に近く、距離は 0.816 です。4色目の LED が、信号を置く次元を1つ増やしています。

③ 送って受ける

ランダムなシンボルを送り、LED の数と同じ数の受光素子で受けます。点は受けた強さを色度図に写したもので、赤は取り違えたシンボルです。条件は2つの方式で同じにしています。

見えたこと
  • 4色目は「次元」を増やす。色度図では四角形は三角形より少し広いだけでも、強さの空間では次元が1つ増えるので、信号点どうしを大きく離せる。
  • 一度に点ける LED は3色まで。QLED は四角形を4つの三角形に分けて考え、それぞれの三角形の3色で色を作る。光の合計はいつも同じなので、ちらつかない。
  • 判定は色度より強さで。強さを色度 (x, y) に直すと雑音が混ざり合うので、強さのまま判定したほうが誤りが少ない。
  • 反射にも強い。部屋の反射で前のシンボルの光が残ると点がずれるが、点どうしが離れている QLED のほうが崩れにくい。
  • 平均の色が白に近い。QLED の信号点の平均は (0.33, 0.33) の白に近い。照明としても使いやすい。
  • 代わりに部品が増える。LED、フィルタ、受光素子が1組ずつ増える。
  • QLED の4色の座標と、4・8・16-CSK の信号点(各 LED の強さ)は、R. Singh, T. O'Farrell, J. P. R. David, "An Enhanced Colour Shift Keying Modulation Scheme for High Speed Wireless Visible Light Communications", IEEE/OSA Journal of Lightwave Technology, 2014 (著者版) の Table I と Table V の値です。「損失ともれあり」の行列も、同じ論文の式 (12) (13) の値を、LED の並び順 (青から赤) に当てはめて使っています。
  • TLED は IEEE 802.15.7 の CSK で、上の論文と同じ色の組 (青 0.169, 0.007 / 黄 0.402, 0.597 / 赤 0.734, 0.265) です。4-CSK は3つの頂点と中心の4点です。8-CSK と 16-CSK は、規格の信号点の位置を確かめられませんでした。そこで、上の論文にある最小距離 (0.47 と 0.27) と同じになる格子の配置で代用しています。
  • 色は、規格と同じく各 LED の強さの重み付き平均 (x = Σ Pixi) で計算しています。色度図の外周は CIE 1931 等色関数 (CIE, DOI 10.25039/CIE.DS.xvudnb9b, CC BY-SA 4.0) から計算しました。背景の色は目安です。
  • SNR は「LED の光の合計 (1W) と、受光素子1つあたりの雑音」の比 10 log10(1/σ²) としています。受光素子の感度は 1 A/W です。論文の横軸は Eb/N0 なので、dB の値はそのままは比べられません。論文では、QLED の利得は Eb/N0 で約 2.9〜4.4 dB と報告されています。
  • 反射による遅延の広がりは、論文と同じ指数減衰のインパルス応答 (rms 遅延の広がり = 時定数の半分) で、等化はしていません。受信側は各シンボルの時間ぶん光を積分するものとしています。論文の Dt はビット時間で割った値ですが、このページの受信モデルではその定義だと影響がほとんど出ないため、シンボル時間で割った値にしています。そのため、数値は論文と直接比べられません。
